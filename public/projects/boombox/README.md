# Boombox images

Upload the Boombox photos **here** (`public/projects/boombox/`), named
sequentially:

```
boombox1.jpg   <- cover photo (shown first)
boombox2.jpg
boombox3.jpg
boombox4.jpg
boombox5.jpg
```

They render on `/projects/boombox` automatically:

- `boombox1.jpg` is the **cover** and appears at the top.
- `boombox2.jpg` … `boombox5.jpg` stack in numeric order below the text.

Any common image type works (`.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`,
`.gif`, `.svg`). Files that don't exist yet are simply skipped, so you can
upload them one at a time. This README is ignored (only image files are shown).
