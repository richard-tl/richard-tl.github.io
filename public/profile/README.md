# Profile photo

Drop your headshot in this folder.

1. Add a file here named `headshot.jpg` (or `.png`, `.webp`, etc.).
2. If you use a different name/extension, update `profile.photo` in `lib/content.ts`
   to match — e.g. `photo: "/profile/me.png"`.
3. A square image works best (it is displayed in a 1:1 box).

Until a matching file exists, the site shows a clean grey placeholder box.
