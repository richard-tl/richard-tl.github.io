The masonry photo grid in the Portfolio → **Art** tab.

Drop these files here (names must match `artGallery.photos` in `lib/content.ts`):

- `row2p1.png`, `row2p2.png`, `row2p3.png`, `row2p4.png`
- `row3p1.png`, `row3p2.png`, `row3p3.png`, `row3p4.png`

Missing files won't render. Formats: `.png`, `.jpg`, `.jpeg`, `.webp`.
