# /public/images

Photography and the top spread for the Portfolio → **Art** tab.

Drop these files here (names must match `artGallery` in `lib/content.ts`):

- `grad_flip3.png` — the wide spread image shown centered at the top
- `landscape1.png`, `landscape2.png`, `landscape3.png`, `landscape4.png` — landscape photos

The remaining photographs live in the `photos/` subfolder (see `photos/README.md`).

Any file that is missing simply won't render — the layout stays clean until you add it.
Supported formats: `.png`, `.jpg`, `.jpeg`, `.webp` (update the extension in `lib/content.ts` if you use something other than `.png`).
